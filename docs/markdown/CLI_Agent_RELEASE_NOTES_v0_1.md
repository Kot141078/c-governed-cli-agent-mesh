## 0. Release summary

This release introduces and synchronizes **C-Governed CLI Agent Mesh v0.1**, a draft protocol pack for using local, cloud, hybrid, and portable CLI agents as bounded executable workers under persistent `c` governance.

v0.1.1 is a hygiene synchronization layer. It does not change the root doctrine. It closes missing-document gaps, normalizes status claims, and prepares the package for controlled schema extraction and local checking.

Core claim:

> A persistent `c` may use many executable agents, but no executable agent may silently become `c` authority.

Compact formula:

```text
Many executable hands.
One governed continuity.
No silent autonomy.
```

---

## 1. Main contribution

The package defines a governance stack for executable agents operating under `c`:

```text
agent discovery
  -> registry eligibility
  -> handshake/admission
  -> task contract
  -> scoped permission
  -> AB/gate evaluation
  -> sandbox/worktree execution
  -> witness
  -> local checker
  -> review/quorum
  -> memory gate / release gate
  -> rollback/freeze if needed
  -> conformance tests
```

It allows agents to:

```text
inspect
propose
simulate
patch
test
compare
report
```

It does not allow agents to become:

```text
will
memory
sovereignty
judge
release authority
incident authority
retaliatory operator
```
