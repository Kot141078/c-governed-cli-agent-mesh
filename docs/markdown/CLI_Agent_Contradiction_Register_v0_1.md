## 1. Corpus bridge set

### 1.1 Explicit bridge: `c = a + b`

CLI agents are part of `b`. They may extend operational reach, but they do not become `c`, do not replace `a`, and do not own continuity, memory, authority, or final judgment.

### 1.2 Quiet bridge I: cybernetics

The package now has multiple control surfaces: task contract, permission, registry, sandbox, witness, review, memory gate, release gate, local checker, and semantic validators. These are not competing authorities. They are nested gates.

### 1.3 Quiet bridge II: information theory

The v0.1.1 patch reduces ambiguity by converting previously missing concepts into named documents and object families. Remaining ambiguity is now localized in extraction and implementation tasks rather than doctrine.

### 1.4 Earth paragraph

The cabinet now has labels. That does not mean electricity is on, inspected, and signed off. It means the next technician does not have to guess which breaker is the server, which is the bathroom, and which must never be touched without calling the owner.
